## Постановка

Продавец (retail, SaaS, авиакомпания, отель) знает функцию спроса $d(p)$ — зависимость между ценой $p$ и объёмом продаж. Нужно выбрать цену, максимизирующую прибыль $\pi(p) = (p - c)\,d(p)$, где $c$ — удельные издержки. Это классическая задача микроэкономики: монополист с известным спросом. В отличие от newsvendor, спрос детерминированный; в отличие от аукционов, нет ставок и конкуренции за показы.

Введён вектор цен $p \in \mathbb{R}^n$ для $n$ товаров. Модель спроса — изоэластичная с перекрёстными эффектами:

```math
d_i(p) = a_i\, p_i^{-\varepsilon_i} \prod_{j \ne i} p_j^{\gamma_{ij}},
```

где $a_i > 0$ — базовый объём; $\varepsilon_i > 1$ — собственная эластичность спроса по цене; $\gamma_{ij} \ge 0$ — перекрёстная эластичность: как цена $j$ влияет на спрос $i$.

Задача минимизации:

```math
f(p) = -\sum_{i=1}^{n} (p_i - c_i)\, d_i(p) \;+\; \frac{\rho}{2} \sum_{i=1}^{n} \left(\log p_i - \log p_{0,i}\right)^2 \;+\; \frac{\alpha}{2}\, \|p - p_0\|^2 .
```

Слагаемые с $\rho$ и $\alpha$ заменяют ограничения: $\rho$ штрафует **относительное** изменение цены (и не даёт цене уйти к нулю), $\alpha$ — **абсолютное** изменение в рублях.

## Наш пример: линейка напитков в чайной

10 напитков (молочные чаи, фруктовые чаи, прочие) с правдоподобными ценами, себестоимостью и продажами; напитки внутри группы — заменители. Данные синтетические, параметры спроса откалиброваны по текущим ценам.

## Результаты

| Подход | Число обусловленности κ | Итераций до $f - f^{\ast} \le 10^{-8}\lvert f^{\ast}\rvert$ |
|---|---|---|
| GD по ценам $p$ (бейзлайн) | 59.6 | 332 |
| GD по $u = \log p$ | 4.1 | 23 |
| Тяжёлый шар по $\log p$ | 4.1 | 8 |
| Метод Ньютона по $\log p$ | 4.1 | 5 |

* Оптимальные цены увеличивают прибыль на 6.3 % (175 425 → 186 529 ₽/день).
* Без штрафных слагаемых задача неограничена — модель перекрёстного спроса позволяет «разогнать» прибыль, делая заменители бесконечно дорогими.
* Замена переменных $u = \log p$ снижает κ в 14 раз и делает ускоренные методы устойчивыми (в ценах BB1 и тяжёлый шар расходятся).
* Робастная постановка (сглаженный худший случай по ошибке в эластичностях) почти исключает сценарии, где новые цены хуже текущих.
